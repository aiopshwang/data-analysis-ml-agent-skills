# v0.1.0 forward-test record

Date: 2026-08-23

## Setup

An independent agent that did not author the tested skill received:

- the [Run Decision-Grade Data Science](../../skills/running-decision-grade-data-science/SKILL.md) skill;
- the unseen [synthetic renewal-risk fixture](../fixtures/renewal-risk/README.md);
- a request to determine modeling readiness and produce a decision contract, evidence-based audit findings, and a defensible first experiment plan.

The evaluator was not given the fixture's intended defects or an expected answer. Inputs were read-only and output was written outside the repository.

## Observed behavior

The evaluator declined to fit or report a model and classified the fixture as not ready for efficacy modeling. It independently identified:

- eight activity rows dated after the decision cutoff;
- lifecycle fields that reveal the later outcome;
- one account with conflicting source labels;
- one censored account with an immature and missing label;
- only six mature, unambiguous account-level outcomes;
- a missing renewal-eligibility field;
- mismatch between random row splitting and weekly deployment;
- mismatch between accuracy and the team's top-three contact capacity.

It proposed retaining the fixture as a QA case, rebuilding historical Monday cohorts with point-in-time features and mature labels, using rolling temporal backtests, comparing a transparent heuristic with regularized logistic regression, and evaluating top-three capture before adding complexity.

## Evidence and result

- Fixture SHA-256 values were recorded and matched after the read-only run.
- No model was trained from invalid evidence.
- Material target, label-precedence, and business-value choices remained explicitly unresolved.
- The result distinguished supported, conditional, contradicted, and not-tested claims.

Result: **pass for the tested end-to-end readiness scenario**.

## Limits

This is one forward test of the lifecycle orchestrator, not proof that every skill behaves correctly on every domain or agent host. Trigger routing, specialist workflows, and future regressions remain covered by the golden prompt set, peer review, repository checks, and additional release testing.
