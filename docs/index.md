# Decision-Grade Data Science

Open-source agent skills that turn ambiguous questions and messy data into auditable analyses and decision-ready models.

## The workflow

    frame the decision
      → audit data and ground truth
      → design a leakage-safe experiment
      → validate models and claims
      → diagnose failures
      → ship reproducible results

Start with the [project README](https://github.com/aiopshwang/data-analysis-ml-agent-skills#readme), read the [methodology](methodology.md), or inspect the [evaluation strategy](evaluation.md).
