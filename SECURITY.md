# Security policy

## Supported versions

Security fixes are applied to the latest tagged release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing credentials, private data, prompt-injection payloads that expose third-party information, or an unpatched exploit.

Include the affected skill, a minimal reproduction, the likely impact, and any safe mitigation you have already tested. You should receive an acknowledgement within seven days.

## Trust boundary

These skills provide instructions and templates. They do not grant an agent permission to access data, run costly jobs, modify production systems, or publish results. Users must review skills before installation and keep normal tool permissions and human approval controls in place.
